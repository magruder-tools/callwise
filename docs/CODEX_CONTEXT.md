# Optional connected apps

Use the installed Callwise app. Settings → Advanced → Codex and connected apps offers ChatGPT browser sign-in and app discovery. The Codex helper is bundled; no global npm install or Terminal is needed.

Select only apps marked ready and explicitly allow them. **Find related notes in my apps** on Ready runs pre-call research through the existing read-only bridge. During a call, research runs only when explicitly asked. Verified record excerpts carry provenance into materials and citations. The bridge refuses write tools, approvals, permission escalation and interactive actions. Search cannot silently change client scope after a conversation begins; create a new call first.

The browser sample disables external connectors. Personal authentication is never bundled. See [Architecture](ARCHITECTURE.md) and [Privacy](PRIVACY.md).
